Poznámka: Analýza emocí je založena na viditelných výrazech tváře a nemusí vždy odpovídat skutečným pocitům člověka.

ℹ️ Jak to funguje

  1. Zadejte váš Claude API klíč (klíč se ukládá pouze v prohlížeči)
  2. Nahrajte fotografii lidské tváře
  3. Claude AI analyzuje výraz tváře a určí emoce
  4. Získáte detailní zprávu o rozpoznaných emocích

🔒 Soukromí

Váš API klíč je uložen pouze v prohlížeči a nikdy se neposílá jinam než přímo do Claude API. Fotografie se zpracovávají pouze prostřednictvím Anthropic API a nejsou ukládány.
